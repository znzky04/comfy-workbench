# Historical source archive — disabled

These files document earlier experiments. Python modules exit immediately before
imports or side effects; batch launchers also exit without spawning processes.
Their historical bodies are not supported code and must not be re-enabled.

Use the compatibility scripts in the repository root or `comfy-demo` instead.
The supported implementation only connects to a user-managed ComfyUI instance.
Old comments, private-store access and automatic startup code describe the past,
not current behavior. No historical images or workflow originals were removed.
